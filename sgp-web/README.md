# SGP Web

## Requisitos

- Node.js 22 ou superior
- pnpm

Caso ainda não tenha o pnpm, instale com:

```bash
npm install -g pnpm
```

## Instalação

Instale as dependências:

```bash
pnpm install
```

## Rodando a aplicação

Inicie o servidor de desenvolvimento:

```bash
pnpm dev
```

Acesse a aplicação em:

```text
http://localhost:5173
```
